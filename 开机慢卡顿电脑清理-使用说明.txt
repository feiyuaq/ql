开机慢卡顿电脑清理  使用说明
==================================================

【这是什么】

解决以下问题:
  - 开机慢, 要等很久才能进系统
  - 加载桌面时黑屏, 只有鼠标
  - 电脑运行一段时间后变卡
  - C盘空间不足, 垃圾文件堆积

工具会扫描你的电脑, 找出拖慢开机的原因, 并提供一键修复或
逐项选择修复。所有操作可回滚, 不会删除你的个人文件。


【怎么运行】

1. 双击 "开机慢卡顿电脑清理.cmd"
2. 弹出权限提示时, 点【是】
   (必须管理员权限, 点【否】或关掉窗口程序会直接退出)
3. 出现菜单后选择功能


【菜单说明】

  [1] 全面检测
      只看不改。列出所有问题, 不做任何修改。
      建议先跑这个看看自己有什么问题。

  [2] 检测并修复
      会先检测, 然后列出可修复项。
      接着你可以选:
        [1] 一键修复  - 自动修复所有推荐项
        [2] 逐项选择  - 自己勾选要修哪几项
        [0] 取消      - 不做任何修改

  [3] 垃圾清理
      分三部分:
        A. 磁盘垃圾 - 临时文件/浏览器缓存/回收站/系统日志等
        B. 系统官方清理工具 (DISM, 推荐)
        C. 注册表清理 - 仅移除确定安全的残留项
      同样支持一键清理 或 逐项选择。

  [4] 磁盘基准测试
      实测硬盘读取速度。数值越低, 开机越慢。
      参考值:
        机械硬盘 5400转  40-90 MB/s
        机械硬盘 7200转  80-150 MB/s
        固态硬盘 SATA   400-550 MB/s
        固态硬盘 NVMe   1500-3500 MB/s

  [5] 回滚设置
      把之前改过的设置还原回去。
      每次修复都会自动备份, 后悔了可以用这个恢复。

  [0] 退出


【支持的操作系统】

  完全支持 (推荐):
    Windows 11        Build 22000 及以上 (含 23H2 / 24H2)
    Windows 10        Build 10240 及以上 (含 20H2 / 21H2 / 22H2)
    Windows 8.1       Build 9600
    Windows 8         Build 9200
    Windows Server 2016 / 2019 / 2022

  部分支持 (会提示, 少数功能降级):
    Windows 7 / Server 2008 R2
      程序可以运行, 以下功能降级或不可用:
        - 开机计划任务扫描 (无 ScheduledTasks 模块)
        - 物理磁盘健康信息 (无 Storage 模块)
        - 快速启动开关 (该功能 Windows 8 才引入)
      但以下功能仍完整可用:
        - 磁盘扫描与修复 (改用 Win32_LogicalDisk 枚举磁盘)
        - 开机耗时分析
        - 垃圾清理 (含浏览器缓存)
        - 注册表残留清理
        - 开机自启项扫描

  不支持:
    Windows Vista / XP / Server 2008 及更早版本
      程序会明确拦截并说明原因

  检测方式:
    程序启动时自动检查系统版本与必要模块, 不满足时明确提示,
    不会运行到一半崩溃。判断依据是 Build 号 + Storage 模块是否存在
    (Windows 7 与 Windows 8.1 的 Build 号相同, 只看版本号会误判)。


【依赖说明】

  操作系统   : Windows 8 及以上 (Win7 部分功能降级)
  运行环境   : 系统自带 PowerShell 5.1, 无需安装任何软件
  网络       : 不需要, 全部离线运行
  权限       : 需要管理员权限
  磁盘占用   : 扫描时会产生一定 IO, 机械盘可能需要 5-20 分钟


【重要提醒】

* 所有改动都会自动备份, 可以用 [5] 回滚还原。
  备份位置: C:\ProgramData\KaQiCleanup\backups\

* 修复后需要【重启电脑】才能完全生效。

* 磁盘扫描可能需要 5-20 分钟, 中途请不要关机。

* 本工具不会删除你的任何个人文件。
  但"清理垃圾文件"里的"回收站"选项会永久删除回收站内容,
  执行前会单独询问, 默认不勾选。

* 磁盘扫描期间如果提示"卷正在使用", 修复会自动安排在下次重启时执行。


【关于注册表清理的说明】

本工具只做两类确定安全的注册表清理:

  1. 失效的开机启动项
     某些程序被卸载后, 开机启动项却还留在注册表里。
     这些项每次开机都会让系统尝试启动一个不存在的程序,
     产生错误、拖慢启动。移除它们是安全的。

  2. 卸载残留项
     程序目录和卸载程序都不存在, 但"已安装程序"列表里还有记录。
     移除后列表变干净。删除前会备份信息到备份目录。
     (判定时同时校验安装路径和卸载程序, 避免误删仍安装的软件)

本工具【不会】做以下市面常见但有风险的操作:
  - 不会"优化""压缩""碎片整理"注册表
  - 不会删除注册表中的历史记录、最近使用列表
  - 不会修改 HKEY_LOCAL_MACHINE\SYSTEM 等核心键
  - 不会手动删除 C:\Windows\Installer 和 WinSxS
    (这类目录手动删除会导致软件无法修复或系统损坏,
     工具改用 Windows 官方的 DISM 命令安全清理)

这些操作对性能没有实际帮助, 反而可能导致软件异常。


【常见问题】

Q: 提示"没有权限"怎么办?
A: 必须点【是】授权。Windows 10/11 需要管理员权限才能修改
   系统启动项和磁盘设置。

Q: 能检测出开机慢的真正原因吗?
A: 能。工具会分别检测:
   - 硬盘类型和实际读取速度 (随机多文件冷读, 不受缓存干扰)
   - 开机自启项数量 (注册表/启动文件夹/服务/计划任务)
   - 磁盘文件系统是否损坏
   - 快速启动是否开启
   - 临时文件与缓存占用

Q: 为什么建议加装固态硬盘?
A: 如果检测显示硬盘是机械硬盘且速度低于 60MB/s, 那么加装
   固态硬盘是唯一能根治开机慢的方法, 效果是软件优化的 3-5 倍。
   软件层面的优化在机械硬盘上已经接近极限。

Q: 会删掉我的软件吗?
A: 不会。本工具只禁用"开机自启", 不会卸载任何软件。
   卸载残留清理也只在程序目录和卸载程序都已不存在时才执行。
